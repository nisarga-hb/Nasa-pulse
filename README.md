# Nasa Pulse 
This ptoject is built by following [this guide](https://stardance.hackclub.com/missions/nasa-page/guide)
Made during stardance 2026
From Nisarga in Hackclub 0_0

## API calls
- https://api.nasa.gov is being used to fetch the text that is being diplayed
- https://science.nasa.gov for image fetching because for some reason the nsas APOD api is failing to provide it
- Weather api to display weather of any city from https://openweathermap.org/current 

## Tech stack
- Html, CSS and Vanilla JS for my front end
- vite for build and development

## Colors used in the site
- `#100224` — dark purple background
- `#FF4FD8` — bright pink accent
- `#6C3CFF` — purple gradient accent
- `#FFE564` — yellow links
